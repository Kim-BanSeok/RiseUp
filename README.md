## ✨ 주요 기능

- 🔔 **스마트 알람**: 반복 설정, 그룹 분류, 우선순위 관리
- ⏱️ **다양한 타이머**: 카테고리별 분류, 템플릿 시스템
- ⏰ **정밀 스톱워치**: 랩 타임 기록, 밀리초 단위 정확도
- 🎮 **미니게임**: 점수 기록, 통계 관리
- 🛠️ **유틸리티 도구**: 계산기, 메모, 손전등 등
- 🎨 **커스터마이징**: 동적 탭 관리, 테마 설정

## 🚀 빠른 시작

### 필수 요구사항

- Node.js 18.0.0 이상
- React Native CLI
- Android Studio (Android 개발용)
- Xcode (iOS 개발용)

### 설치 및 실행

```bash
# 1. 저장소 클론
git clone https://github.com/your-username/RiseUp.git
cd RiseUp

# 2. 의존성 설치
npm install

# 3. Metro 서버 시작
npm start

# 4. 앱 실행
npm run android  # Android
npm run ios      # iOS
```

- **프레임워크**: React Native 0.72.0
