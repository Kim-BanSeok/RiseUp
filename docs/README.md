# 📚 RiseUp 프로젝트 문서

이 폴더는 RiseUp 프로젝트의 개발 과정에서 발생하는 모든 코드 리뷰, 변경사항, 아키텍처 결정을 기록합니다.

## 📁 폴더 구조

```
docs/
├── README.md              # 이 파일
├── code-reviews/         # 코드 리뷰 기록들
│   ├── screens/         # 화면별 리뷰
│   ├── components/      # 컴포넌트별 리뷰
│   ├── utils/          # 유틸리티별 리뷰
│   └── navigation/     # 네비게이션 리뷰
├── change-logs/         # 변경 기록들
│   ├── daily/          # 일일 변경사항
│   ├── features/       # 기능별 변경사항
│   └── bug-fixes/      # 버그 수정 기록
└── architecture/        # 아키텍처 결정 기록
    ├── folder-structure.md
    ├── state-management.md
    └── design-patterns.md
```

## 📝 문서 작성 규칙

### 코드 리뷰 파일
- 파일명: `{파일명}-review-{날짜}.md`
- 형식: 문제점, 개선사항, 권장사항 포함

### 변경 기록 파일
- 파일명: `{기능명}-{날짜}.md`
- 형식: Before/After, 이유, 영향도 포함

### 아키텍처 문서
- 설계 결정의 이유와 배경
- 장단점 분석
- 향후 개선 방향

## 🎯 목적

1. **개발 히스토리 추적**: 왜 이런 결정을 했는지 기록
2. **학습 자료**: 향후 유사한 문제 해결시 참고
3. **팀 커뮤니케이션**: 변경사항의 명확한 전달
4. **코드 품질 향상**: 지속적인 개선점 발견
