### 1. 🎯 탭 네비게이션 가려짐 문제 해결
**우선순위**: 높음 | **소요시간**: 1시간

#### 문제점
- 사용자가 스크린샷으로 제보한 탭바에 페이지가 가려지는 문제
- 여러 화면에서 하단 콘텐츠 접근 불가

#### 해결책
```typescript
// 표준 패딩 적용
style={[styles.container, { 
  paddingTop: insets.top,
  paddingBottom: insets.bottom + 100 // 탭바 높이 + 여유공간
}]}
```
